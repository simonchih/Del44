Windows PowerShell or Command Prompt (from this project directory):
  .\build.cmd

This does not require enabling PowerShell scripts or changing execution policy.
build.ps1 is also available where PowerShell scripts are already enabled.

Manual equivalent using the project's virtual environment:
  .\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
  .\.venv\Scripts\python.exe -m PyInstaller --noconfirm --workpath build/verified d44.spec

Output: dist\d44.exe
Do not use the global PyInstaller command: it may use an incompatible Python.
